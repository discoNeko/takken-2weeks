# 爆速2週間 宅建

宅地建物取引士試験を14日で一周するための学習サイト。

**公開ページ:https://disconeko.github.io/takken-2weeks/** (GitHub Pages。`main` ブランチに push すると自動で反映される)

ビルドもサーバーも不要なので、ローカルでは `index.html` をブラウザで開けば使える。

```bash
open index.html
```

## できること

- **14日カリキュラム**:宅建業法5日 → 権利関係4日 → 法令上の制限3日 → 税・その他1日 → 総復習1日
- **一問一答 198問**:各日の講義の直後に○×で確認。解説つき
- **苦手リスト**:間違えた問題だけを自動で集め、正解すると消える
- **ランダム模試**:本試験と同じ科目配分(業法20・権利14・法令8・税その他8)で50問
- **数字暗記シート**:113項目。数字を隠してタップで確認、キーワードで絞り込み
- 試験日までのカウントダウン、進捗の保存(ブラウザの localStorage)、ライト/ダーク切替

## 構成

```
index.html
assets/style.css      見た目
assets/app.js         画面の切替・クイズ・進捗保存
data/core.js          試験日・科目の定義
data/days-*.js        各日の講義(HTML)と一問一答
data/numbers.js       数字暗記シート
```

内容を直すときは `data/` の該当ファイルを編集する。問題は `{ q: 問題文, a: true(○)/false(×), ex: 解説 }` の形式。

## 注意

- 内容は令和8年(2026年)4月1日時点の法令を前提にした要約。区分所有法の改正(令和8年4月施行)など新しい論点、統計問題、税制の適用期限は、最新のテキスト・公式情報で確認すること。
- 一問一答は論点確認用。本試験は四肢択一なので、仕上げは過去問を時間を計って解く。
- 進捗はブラウザごと・開き方ごと(公開ページ、`file://`、`http://localhost` はそれぞれ別)に保存される。端末間の同期はない。
